Skyline Apartments - Luxury Real Estate Platform

📋 Overview

Skyline Apartments is a high-end, responsive real estate landing page built with React.js and Tailwind CSS. Designed for the luxury market, it features a sophisticated "Dark Navy & Gold" aesthetic and a suite of interactive tools for potential buyers.

Live Demo: [Insert Your Vercel/Netlify Link Here]

✨ Key Features

Interactive Map: Custom interactive map view with property pins and tooltips.

Smart Filtering: Advanced search with filters for Price, Type, and Bedrooms.

Immersive Modals: Full-screen property details with image galleries.

Responsive Design: Fully fluid layout that works on Mobile, Tablet, and Desktop.

Cinematic UI: Smooth animations, glassmorphism effects, and video integration.

🛠️ Tech Stack

React 18

Vite (Build Tool)

Tailwind CSS (Styling)

Lucide React (Icons)

🚀 Getting Started

Prerequisites

Node.js (v14 or higher)

Installation

Clone the repository:

git clone [https://github.com/yourusername/skyline-apartments.git](https://github.com/yourusername/skyline-apartments.git)


Navigate to the project directory:

cd skyline-apartments


Install dependencies:

npm install


Start the development server:

npm run dev
